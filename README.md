# daisy-flask

A minimal starter repository for building modern web applications with Flask, Tailwind CSS (v4), and DaisyUI.

---

## Folder Structure

```text
daisy-flask/
├── static/
│   ├── src/
│   │   └── input.css        # Source CSS file with Tailwind & DaisyUI imports
│   └── dist/
│       └── output.css       # Compiled CSS file (generated by Tailwind CLI)
├── templates/
│   └── index.html           # Main HTML layout/template
├── app.py                   # Main Flask application entry point
├── package.json             # NPM package configuration & scripts
├── requirements.txt         # Python dependencies
└── README.md
```

---

## Tech Stack

* **Backend:** Flask
* **Styling:** Tailwind CSS (v4)
* **UI Components:** DaisyUI

---

## Prerequisites

Before getting started, make sure you have the following installed on your system:

* **Python:** `3.8+`
* **Node.js:** `v18+` (includes `npm` and `npx`)

---

## Quick Start & Setup

### 1. Python Environment Setup

Install Flask and run the application:

```shell
pip install flask
python app.py
```

### 2. Install Tailwind CSS

Install Tailwind CSS CLI as a dev dependency:

```shell
npm install tailwindcss @tailwindcss/cli --save-dev
```

### 3. Install DaisyUI

Install DaisyUI as a dev dependency:

```shell
npm install -D daisyui@latest
```

### 4. Configure CSS

Create `./static/src/input.css` and add the Tailwind and DaisyUI directives:

```css
/* static/src/input.css */
@import "tailwindcss";
@plugin "daisyui";
```

### 5. Build and Watch CSS

Run the Tailwind CLI to compile your styles and watch for file changes during development:

```shell
npx @tailwindcss/cli -i ./static/src/input.css -o ./static/dist/output.css --watch
```

---

## HTML Integration

Include the compiled `output.css` inside your template (`templates/index.html`):

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Daisy Flask</title>
    <link rel="stylesheet" href="{{ url_for('static', filename='dist/output.css') }}">
</head>
<body class="bg-base-200 text-base-content min-h-screen flex items-center justify-center">
    <div class="text-center">
        <h1 class="text-4xl font-bold text-primary mb-4">Namaste, Flask!</h1>
        <button class="btn btn-primary">DaisyUI Button</button>
    </div>
</body>
</html>
```

---

## Production Build

To minify your CSS output for production deployment, run:

```shell
npx @tailwindcss/cli -i ./static/src/input.css -o ./static/dist/output.css --minify
```
